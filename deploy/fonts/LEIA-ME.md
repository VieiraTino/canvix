# Fontes da marca (fora de git)

Esta pasta é copiada para `/usr/local/share/fonts/vds/` na imagem, para o
render no servidor (`export_design_url`) usar as fontes da marca.

Os ficheiros não vão para o repositório (o fork é público e a licença da
Vogun não está confirmada). No servidor ficam aqui:

- `Vogun-Medium.otf`, `Vogun-MediumItalic.otf`
- `Montserrat-Light/Regular/Italic/Medium/SemiBold/Bold/BoldItalic.ttf`

Guardar uma cópia fora do servidor. Os nomes que o Canvix dá às fontes
carregadas (ex.: "Montserrat Regular") são mapeados em `../fonts-local.conf`.
